PARMCO: Real-Time Mobile Motor Control

PARMCO is a cutting-edge mobile application designed for direct, real-time command and feedback of a remote motor system, focusing on reliability and a modern user experience.

Project Architecture and Implementation

Software Stack (Android)

The application is natively developed in Kotlin, utilizing the latest Android frameworks for a high-performance, responsive interface.

  • Jetpack Compose: Used for building the entire UI, including custom, animated components like the Rotary Speed Dial and real-time RPM display.
  • Kotlin Coroutines: Manages asynchronous operations like Bluetooth communication without blocking the main thread.
  • Android SDK: Handles device-level interactions, including necessary Bluetooth permissions across various Android versions.

Bluetooth Communication Layer

Communication with the physical motor controller (a designated Raspberry Pi) is handled via the classic Bluetooth Serial Port Profile (SPP).

Protocol: Bluetooth RFCOMM (SPP)

Reliable, bidirectional streaming of text commands and data over Bluetooth classic.

Hardware Target: RP4 MAC Address (`2C:CF:67:53:61:32`)

The app targets a specific device for immediate connection attempts.

Data Handling: Dedicated Read Thread

A separate Coroutine continuously monitors the input stream, parsing incoming strings (expected to be the current RPM value) in real-time.

Embedded Control Implementation (Raspberry Pi C)

The core control logic runs directly on the Raspberry Pi 4 using **bare-metal C** and direct GPIO register access (via `mmap`) for maximum speed and control precision.

GPIO Pin Mapping

  • Motor Direction (IN1/IN2): GPIO17 / GPIO27
  • PWM Speed Control (EN1): GPIO18 (ALT5)
  • RPM Feedback (IR Sensor): GPIO22 (Input)

The PWM logic uses **inverted logic** (0% duty = max speed, 100% duty = stopped).

Timing and RPM Calculation

The RPM is calculated using a dedicated, high-priority **`pthread`** that constantly monitors the IR sensor pin for rising edges.

  • PWM Frequency: 1 kHz
  • Pulses per Rotation: 3 Pulses
  • RPM Update Interval: 0.3 Seconds

Closed-Loop PID Tuning

The Automatic (Target RPM) mode uses a fixed-point Proportional-Integral (PI) control loop running inside the RPM thread.

  • Proportional Gain (Kp): 0.015
  • Integral Gain (Ki): 0.001
  • RPM Deadband: ±30 RPM

Dual Control Modes and Command Structure

1.

Manual PWM Mode

In Manual mode, the user directly controls the motor's power output via the **Duty Cycle** (0-100%). This is an open-loop control system.

Command Format:
"50" (Sets PWM to 50%)
"START" / "STOP"
2.

Automatic Target RPM Mode

In Automatic mode, the app requests a specific **Revolutions Per Minute (RPM)** target. The motor controller handles the necessary closed-loop (PID) logic on the hardware side.

Command Format:
"TARGET:4500" (Requests 4500 RPM)
"FORWARD" / "REVERSE"
